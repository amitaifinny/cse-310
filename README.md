# Hello World Program

This is a very simple program that prints hello world letter by letter in the console.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Simply run the program. No compiling in Python.

Instructions for using the software:

1. Run the program
2. View the console and see hello world displayed letter by letter, line by line.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Python Installed (newest version preferable)
* IDE installation
